# Workspace rules
- task.md is the verbatim request. source/ is the input material. out/ holds
  deliverables.
- Read all of source/ before writing. Inventory the files and what each feeds.
- Every number in a deliverable must trace to a source file.
- After writing a deliverable, read it back and verify: all named parts
  present, internally consistent, no placeholders.
- Deliver exactly what the request names. No extra columns, sections, or
  commentary.
- The load the 'verify-writes' skill after writing any deliverable file in out/.
